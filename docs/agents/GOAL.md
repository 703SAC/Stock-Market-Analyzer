# GOAL — 주식 AI 에이전트 시스템 북극성

> 단일 진실 공급원(SSOT). 무엇을/왜 만드는지의 불변 기준. 변경은 신중히.

## 0. 페르소나
퀀트 + AI 트레이딩 데스크를 구축하는 수석 아키텍트. 출처: [PROMPT.md](../../PROMPT.md).

## 1. 불변 원칙 (Non-negotiables)
1. **비용 0원 우선**: 메인 분석은 무료 티어 `Gemini`(google-genai). KIS·Naver·RSS·Telegram 모두 무료 경로. 유료(Claude)는 자리만 예약하고 기본 비활성.
2. **환각 제로 (정량/정성 분리)**: 주가·거래량·기술지표·CAN SLIM 조건식은 **절대 LLM에 맡기지 않고 Pandas 수식으로 선필터링**. LLM은 정성 해석(JSON Schema 강제)만 담당.
3. **맥락 주입 (메가 내러티브)**: 당일 뉴스 파편이 아니라 `[종합 시황]·[일정]·[그룹사/테마 역학]`을 누적 저장소에서 주입해 "숲"을 본다.
4. **Adapter 경계**: Router → Feature service → Adapter → External API. `open-trading-api` 수정 금지, `kis-ai-extensions` 런타임 import 금지.
5. **출처 구분 명시**: 기사/DART/가격 데이터 출처를 분리하고, 단정 대신 "가능성·확인 필요" 표현.

## 2. 3대 에이전트 미션
| # | 에이전트 | 미션 | 핵심 출력 |
|---|---|---|---|
| ① | **모니터링** | KIS 연동, 낮(국장)/밤(미장) 교대 스케줄, 장마감 후 로그 기반 Gemini 일일 리포트 → 텔레그램 | 일일 마감 리포트 + 알림 |
| ② | **시장 판단** | 타임라인(장전/장중/마감) 뉴스 스크래핑(Naver/RSS+Trafilatura), 메가 내러티브 종합 시황 브리핑 | 시황 브리핑 |
| ③ | **전략** | Pandas CAN SLIM 정량 필터, 상한가/거래량 폭발 종목의 인과관계(테마·일정·그룹사) 분석 | 인과 분석 리포트 |

## 3. 시스템 백본
**메가 내러티브 맥락 저장소**(SQLite): `market_digest`(일별 종합시황) · `event_calendar`(일정) · `group_map`(그룹사·테마) · `narrative_memory`(누적 내러티브). 세 에이전트가 read/write로 유기적으로 연동되며, 모니터링이 쓴 마감 시황 → 시장판단이 읽고 → 전략이 인과분석에 활용하는 루프를 형성한다.

## 4. 성공 기준 (Definition of Done)
- 세 에이전트가 맥락 저장소를 통해 데이터를 주고받으며 자동 동작.
- 모든 정량 연산은 Pandas, 모든 LLM 출력은 JSON Schema 검증 통과.
- 외부 API는 전부 adapter mock 단위테스트로 검증(실호출 없이 그린).
- 비용 0원 경로로 일일 리포트 생성·텔레그램 발송이 스케줄로 자동 실행.

## 5. 범위 밖 (MVP 제외)
실시간 자동 주문, 전 종목 무제한 조회, 사용자 입력 Python 코드 실행, 투자 추천 단정 표현, 프론트엔드 시크릿 노출.
